## 维护约定

- 文件名使用 `NN-小写英文短横线.md`，序号两位；目录中的顺序即阅读顺序。
- 根目录的 [README](../README.md) 只保留简介、安装与入口链接，细节写进本目录。
- 已确认的设计决策不直接改写；修订时在文档末尾追加「增补」小节并注明日期（参见 02 的 §12、§13）。
- 文档以简体中文为主；面向公开仓库的入口文档（README、CONTRIBUTING、CHANGELOG）提供中英双语。
